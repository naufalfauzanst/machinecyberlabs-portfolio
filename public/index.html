6 proyek ditampilkan

01

Cybersecurity / Detection engineering

Windows SOC Detection Lab

Pipeline telemetry Windows dan Sysmon ke Splunk, dengan tujuh deteksi yang mencakup encoded PowerShell, failed logons, persistence, dan lampiran email ber-ekstensi ganda.

  • Splunk SPL
  • Sysmon
  • PowerShell
Catatan proyek

Lab masih dikembangkan. Ingestion Gmail dan alert terjadwal sudah divalidasi; polling email secara kontinu belum divalidasi.

Repository
02

Cybersecurity / Incident investigation

Phishing Investigation Lab

Enam kasus latihan: analisis header dan autentikasi email, ekstraksi IOC, investigasi lampiran, serta korelasi bukti dengan alert Splunk.

  • SPF / DKIM / DMARC
  • IOC analysis
  • Splunk
Catatan proyek

Kasus menggunakan simulasi dan akun lab. Verdict dibedakan antara simulasi phishing dan email latihan benign, tanpa mengklaim kompromi nyata.

Repository
03

Cybersecurity / Purple team

SOC Purple Team Lab

Investigasi SSH/SFTP, validasi deteksi EDR, terminasi proses terkontrol, uji isolasi jaringan, dan triage false positive dengan bukti terdokumentasi.

  • LimaCharlie
  • Wireshark
  • Sysmon
Catatan proyek

Respons dilakukan pada VM milik sendiri. Dokumentasi memisahkan hasil yang diamati, keterbatasan pengujian, dan pekerjaan yang belum diimplementasikan.

Repository
04

Machine learning / Computer vision

NeuroVision: Klasifikasi MRI

Eksperimen transfer learning yang membandingkan ResNet50 dan EfficientNetB0 pada empat kelas citra MRI, disertai evaluasi per kelas dan aplikasi web lokal.

  • PyTorch
  • ResNet50
  • EfficientNetB0
Catatan proyek

Prototipe riset skripsi. Kelas “no tumor” merupakan label yang dipelajari model; aplikasi tidak memvalidasi bahwa input merupakan MRI dan belum divalidasi untuk diagnosis klinis.

Repository
05

Machine learning / Natural language processing

HoaxScan: Teks Bahasa Indonesia

Klasifikasi teks berita menggunakan TF-IDF, delapan fitur emosi, dan XGBoost. Aplikasi Flask mendukung training, evaluasi, dan analisis teks individual atau batch.

  • XGBoost
  • TF-IDF
  • Flask
Catatan proyek

Prediksi tidak memverifikasi kebenaran klaim secara independen. Dokumentasi mencatat duplikasi teks lintas split yang dapat melebihkan estimasi performa pada narasi baru.

Repository
06

Machine learning / Time series

Peramalan Harga Minyak

Aplikasi riset LSTM untuk memprediksi harga penutupan minyak menggunakan data historis dan indikator risiko geopolitik, dengan split kronologis dan laporan evaluasi.

  • TensorFlow / Keras
  • LSTM
  • pandas
Catatan proyek

Metrik eksperimen mengukur prediksi satu langkah. Hasil tersebut tidak mengukur akurasi forecast rekursif tujuh langkah atau membuktikan manfaat kausal risiko geopolitik.
